# 编辑器布局规范

[返回 README](../README.md) | [上一节：状态栏](./07-components/status-bar.md)

## 1. 整体布局结构

```
+-------------------+-----------+-----------+
| 标题栏 (36/32px)                         |
+-------------------+-----------+-----------+
| 菜单栏            | 工具栏    |           |
+-------------------+-----------+-----------+
| 工具箱 (240px)    | 积木画布  | 舞台+面板 |
|                   | (自适应)  | (272px)   |
+-------------------+-----------+-----------+
| 状态栏 (28px)                            |
+-------------------+-----------+-----------+
```

## 2. 面板规则

- 所有面板可折叠/展开，折叠时宽度为 0，展开时恢复用户上次设置的宽度。
- 工具箱和右侧面板可拖拽调整宽度，最小宽度 160px，最大宽度 400px。
- 积木画布始终填充剩余空间，最小宽度 320px。
- 在平板竖屏模式下，工具箱折叠为底部横条，舞台置顶。

## 3. 多窗口 (桌面端)

- 每个项目窗口独立，共享同一渲染进程。
- 窗口位置和大小由系统窗口管理器管理，编辑器内部布局规则不变。
