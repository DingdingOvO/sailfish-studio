# 03 - 类型系统设计

[返回 README](../README.md)

## 1. 基本类型

| 类型 | 对应积木 | 说明 |
|------|---------|------|
| `any` | 通用 | 可接受任意值 |
| `string` | 字符串 | UTF-8 |
| `number` | 双精度浮点 | IEEE 754 |
| `float` | 高精度浮点 | 128 位 |
| `long` | 大整数 | 64 位 |
| `bigint` | 无限大整数 | 任意精度 |
| `bool` | 布尔值 | true/false |

## 2. 复合类型

- **结构体**: 用户自定义，字段可包含任意类型。
- **枚举**: 用户自定义，枚举值可比较。
- **列表**: `List<T>`，T 为元素类型。
- **可选**: `T?`，允许值为 null。

## 3. 类型检查

编译时进行类型推断和检查，类型不匹配时抛出编译错误并提供具体位置。`any` 类型在赋值给具体类型变量时必须显式转换，防止隐式类型泄漏。
