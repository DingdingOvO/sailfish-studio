# 弹窗组件规范

[上一节：输入框](./input.md) | [下一节：树形视图](./tree-view.md)

## 1. 类型

### 1.1 模态弹窗 (Modal)

- 用途: 设置面板、项目属性、扩展详情。
- 尺寸: 最小 480px 宽, 最大 80vw 宽, 高度自适应但不超过 80vh。
- 背景: `--bg-elevated`, 圆角 12px, 阴影 0 4px 16px rgba(0,0,0,0.25)。
- 遮罩层: 背景 rgba(0,0,0,0.5), 点击关闭 (可配置)。

### 1.2 确认对话框 (Confirm)

- 用途: 删除确认、退出保存提醒。
- 尺寸: 400px 宽。
- 内容: 标题、描述文本、确认按钮 (右侧)、取消按钮 (左侧)。

### 1.3 通知条 (Toast)

- 用途: 协作加入/离开、扩展安装完成、保存成功。
- 位置: 左下角，距边缘 16px。
- 尺寸: 最大 360px 宽。
- 自动消失: 5 秒后淡出，悬停时暂停计时。

## 2. 交互

- 打开弹窗时，焦点自动移到弹窗内第一个可聚焦元素。
- Esc 关闭弹窗 (所有弹窗)。
- 弹窗内 Tab 键在弹窗内循环，不会焦点逃逸到弹窗后。
