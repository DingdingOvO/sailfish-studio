# 03 Presence

03 - 用户存在感设计

1. 概述

用户存在感系统让协作用户在编辑器中可见，感知彼此的位置和操作。

2. 光标显示

· 每个协作用户的鼠标光标显示为带有其用户颜色的箭头，上方浮动用户名称标签
· 用户名称标签背景为其颜色，文字为白色，字号 --text-xs，跟随光标移动
· 光标位置每 100ms 向其他客户端广播一次（节流，避免高频消息）
· 当光标在积木画布或舞台上时广播，在其他区域（菜单、对话框）时不广播

3. 编辑状态显示

· 某用户正在编辑的积木显示该用户颜色的 2px 边框，透明度 0.8
· 某用户选中的角色在角色列表中高亮显示其颜色背景
· 某用户正在编辑的造型在造型编辑器中显示锁定图标（锁 + 用户颜色 + 用户名 tooltip）
· 某用户正在查看的脚本区域（积木画布滚动位置）不做强制同步

4. 用户列表

· 工具栏右侧显示当前协作会话的参与者头像（最多显示 6 个，超出显示 "+N"）
· 点击头像或 "+N" 展开完整用户列表，包含:
  · 用户名、头像、权限角色
  · 当前状态（活跃/空闲/离线），空闲判定: 2 分钟无操作
  · 正在编辑的文件/角色
· 邀请新成员按钮在列表顶部

5. 加入/离开通知

· 用户加入/离开时，左下角弹出 Toast 通知
· 通知内容: "[用户名] 加入了协作" / "[用户名] 离开了协作"
· 持续时间: 3 秒
· 最多同时显示 3 条通知，超出排队
