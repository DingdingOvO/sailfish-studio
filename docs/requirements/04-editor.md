# 04 - 积木编辑器

[上一章](./03-architecture.md) | [下一章：多人协作](./05-collaboration.md)

## 4.1 编辑器基础
- 全新积木视觉，不模仿 Blockly。
- 拖拽吸附（`MAGNETIC_SNAP_DISTANCE_PX` px）。
- 动态模糊拖尾（`TRAIL_FRAME_COUNT` 帧，透明度 `TRAIL_MAX_ALPHA` → `TRAIL_MIN_ALPHA`）。
- 撤销/重做（`HISTORY_STACK_MAX_DEPTH` 条）。
- 右键菜单：复制、粘贴、删除、注释、折叠。
- 工具箱：内置积木和扩展积木统一显示。

## 4.2 类型系统
创建变量必须选类型，每种类型有专属图标和色差：

| 类型 | 说明 |
|------|------|
| `any` | 通用类型，默认，橙色系 |
| `string` | 纯字符串 |
| `number` | 双精度浮点 |
| `float` | 高精度浮点 |
| `long` | 大整数 |
| `bigint` | 无限大整数 |
| `bool` | 布尔值 |

公有/私有变量分组显示。导入外部项目时默认通用类型。

## 4.2.1 常量

用户可以在编辑器中定义常量，与变量创建流程相同但额外勾选"常量"选项。

**常量的行为**：
- 创建后值不可修改。编辑器不提供"设置常量"积木，直接使用常量名即可引用其值。
- 常量在积木中显示为灰色背景，与变量的橙色背景区分。
- 常量可以导出为 .sfl 的 `const` 声明。
- 导入外部项目时，原项目中的常量保持常量属性。

## 4.2.2 结构体

用户可以定义结构体类型，将多个字段组合成一个复合类型。

**创建结构体**：
- 在变量面板中点击"新建结构体"，输入名称。
- 添加字段：每个字段有名称和类型（可选任意类型，包括其他结构体）。
- 结构体定义后出现在类型下拉菜单中，可作为变量类型、列表元素类型、函数参数类型。

**使用结构体**：
- 创建结构体变量后，通过"读取字段"和"设置字段"积木操作其成员。
- 结构体变量在监视器中以树形结构展示。
- 结构体可以嵌套（结构体的字段可以是另一个结构体）。

## 4.2.3 枚举

用户可以定义枚举类型，限制变量只能取预定义的几个值。

**创建枚举**：
- 在变量面板中点击"新建枚举"，输入名称。
- 添加枚举值（如"上、下、左、右"或"开始、暂停、结束"）。
- 每个枚举值有默认的颜色标识。

**使用枚举**：
- 枚举变量在积木中以下拉选择器展示，只能从定义的枚举值中选择。
- 枚举值可以比较（等于/不等于）。
- 枚举在 .sfl 中编译为 tagged union 或整数常量。

## 4.2.4 可选类型

变量可以标记为"可选"，允许其值为空（null）。

- 创建变量时勾选"可为空"选项，类型标注显示为 `T?`（如 `string?`）。
- 可选类型变量在未赋值时默认为空。
- 使用"如果为空"积木检查可选变量是否有值。
- 非可选变量不得赋值为空，编译时检查。

## 4.2.5 类型别名

用户可以为现有类型创建别名，提高代码可读性。

- 在变量面板中点击"新建类型别名"，输入别名和原类型。
- 别名在类型下拉菜单中显示，与原类型等价。
- 在 .sfl 中编译为 `type 分数 = number`。

## 4.3 高级语言特性
泛型、可选类型、联合类型、类型别名、结构体、枚举、完整函数签名、模块与命名空间、错误处理、常量与不可变数据。

## 4.4 拖拽交互
- 拖出：积木→.sfl、角色→.sprite、背景→.backdrop、造型→图片、声音→音频、项目卡片→.sf、舞台→截图。
- 拖入：图片、音频、.sfl、.sb3/.sf、.sprite、.backdrop、扩展文件。
- 文件暂存区：编辑器关闭前非空则提示保存。
- 桌面端多窗口，Web 端标签页多开（不支持跨标签页拖拽）。
- 平板：拖出改为屏幕边缘菜单。

## 4.5 协作模式下的编辑器行为
- 其他用户编辑的积木显示其颜色边框。
- 同一积木被两人同时拖拽时，先开始的生效。
