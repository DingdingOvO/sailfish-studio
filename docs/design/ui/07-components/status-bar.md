# 状态栏组件规范

[上一节：积木画布](./block-canvas.md) | [下一节：编辑器布局](../08-layout.md)

## 1. 布局

- 高度: 28px
- 背景: `--bg-primary`
- 左区域: 性能仪表盘 (Wasm 内存、纹理缓存、音频缓存、FPS)
- 右区域: 同步状态指示器、缩放级别、光标位置

## 2. 性能仪表盘

- 实时显示: Wasm 内存 (当前/上限, 如 128MB / 256MB)、纹理缓存数量、音频缓存数量、FPS。
- 点击可展开详情面板 (内存分配图、FPS 趋势图)。
- 颜色指示: 内存使用 > 80% 时变橙色，> 95% 时变红色。

## 3. 同步状态

- 已同步: 绿色圆点 + "已同步"
- 同步中: 蓝色旋转图标 + "同步中..."
- 离线: 灰色圆点 + "离线"
