# 02 Extension Lifecycle

02 - 扩展生命周期

1. 生命周期阶段

1.1 注册 (Registration)

· 扩展在编辑器启动或用户安装时注册
· 注册时提供 extension.json 或通过 API 声明积木、设置项
· 注册后积木出现在工具箱中

1.2 加载 (Loading)

· 扩展代码在第一次使用时按需加载（懒加载）
· 加载时分配沙箱环境 (Web Worker 或独立进程)
· 加载超时: 10 秒，超时后提示用户并禁用该扩展

1.3 执行 (Execution)

· 积木触发时调用扩展的 execute 方法
· 执行超时: 单次调用最长 5 秒，超时后终止并报错
· 扩展可访问 RuntimeState 读写变量、列表、广播消息

1.4 暂停 (Suspension)

· 项目停止运行时，扩展进入暂停状态
· 暂停时扩展不应执行任何后台操作
· 恢复执行时通过 on_resume 回调通知扩展

1.5 卸载 (Unloading)

· 用户禁用或卸载扩展时触发
· 扩展应清理资源 (定时器、网络连接、事件监听)
· 扩展进程被终止，所有内存释放

2. 状态图

```
[已安装] → (加载) → [已加载] → (执行) → [运行中]
                 ↓                    ↓
             [错误/超时]          [暂停/停止]
```
