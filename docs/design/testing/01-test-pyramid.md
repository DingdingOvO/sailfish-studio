# 01 - 测试金字塔

[返回 README](../README.md)

## 1. 层次

| 层次 | 占比 | 描述 | 工具 |
|------|------|------|------|
| 单元测试 | 70% | 每个 Rust 函数、TypeScript 函数独立测试 | cargo test, Vitest |
| 集成测试 | 20% | 模块间交互、IPC 协议、API 端点 | cargo test, Vitest + MSW |
| 端到端测试 | 10% | 完整用户流程: 创作→运行→保存→打包 | Playwright |

## 2. 覆盖要求

- 所有公共 API 必须有单元测试。
- 所有 IPC 方法必须有集成测试。
- 每个用户故事至少一个端到端测试。
- 总覆盖率 ≥ 95%。

## 3. 性能测试

- **编译器**: 1000 积木编译 < 200ms。
- **渲染**: 1000 角色 60fps。
- **协作**: 延迟 < 200ms。
- 使用 criterion (Rust) 和 Lighthouse (Web) 进行基准测试。
