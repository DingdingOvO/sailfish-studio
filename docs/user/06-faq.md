# 06 - 常见问题

## 性能相关

**Q: 项目运行卡顿怎么办？**
A: 尝试以下方法: (1) 减少克隆体数量 (2) 使用加速模式 (3) 在菜单中运行"优化所有资源"压缩素材 (4) 检查内存仪表盘是否超过限制。

**Q: 大文件导入很慢？**
A: 图片超过 10MB 时会收到警告。建议在导入前压缩图片 (编辑器内置一键优化功能)。

## 文件相关

**Q: .sf 和 .sb3 有什么区别？**
A: .sf 是 Sailfish Studio 的新格式 (SQLite 数据库)，比 .sb3 (ZIP) 更紧凑，支持实时保存和增量写入。Sailfish Studio 同时兼容 .sb3 和 .sb2。

**Q: 如何将 .sb3 项目转为 .sf？**
A: 在编辑器中打开 .sb3 文件，然后"另存为"选择 .sf 格式即可。

## 协作相关

**Q: 协作时冲突怎么办？**
A: 积木树冲突自动解决（使用 OT 算法）。变量以最后写入为准。造型编辑期间锁定，不会产生冲突。离线编辑后恢复连接时如有冲突，系统会弹出对话框让您选择保留哪个版本。

**Q: 最多多少人同时协作？**
A: 单个房间最多 32 人。

## 扩展相关

**Q: 如何开发扩展？**
A: 参考扩展开发文档 (API 参考)，使用 JS、Rust 或 C++ 编写，提交到扩展市场。

**Q: 社区渠道的扩展安全吗？**
A: 社区渠道的扩展未经官方审核，可能包含风险。请谨慎安装，或在安装前查看社区评价。

## 桌面端相关

**Q: 桌面版和 Web 版有什么区别？**
A: 功能基本一致。桌面版支持离线使用、原生文件对话框、自动更新、更好的性能 (原生子进程)。

**Q: 如何更新桌面版？**
A: 桌面版启动时自动检查更新，有新版本会提示下载安装。
