# 05 - 图标系统

[返回 README](../README.md)

## 1. 图标库

使用 `@phosphor-icons/react`，选择 Regular 风格，2px 描边，16px 和 20px 两种尺寸。Phosphor 图标设计统一、线条简洁，适合专业工具界面。

## 2. 尺寸与颜色

| 场景 | 尺寸 | 颜色 |
|------|------|------|
| 工具栏按钮 | 20px | `--text-secondary` |
| 菜单项图标 | 16px | `--text-secondary` |
| 树节点图标 | 16px | `--text-secondary` 或类别色 |
| 状态指示器 | 16px | 状态色 |

- 悬停/选中时：图标颜色变为 `--color-primary`。
- 禁用时：图标颜色使用 `--text-disabled`。

## 3. 图标使用规则

- 所有交互元素图标必须配文本标签 (Tooltip 或可见文本)。唯一的例外是"播放/停止"等极度通用且用户已形成肌肉记忆的图标。
- 同一功能在全界面使用相同图标。例如，"设置"在工具栏、菜单、树形导航中统一使用 Gear 图标。
- 文件类型图标使用语义化颜色：.sf 文件用蓝色，.sfl 文件用绿色，.sb3 文件用橙色。
- 自定义图标 (如扩展提供的图标) 需经审核，确保与系统图标风格统一。
