# 02 - 积木参考

## 运动类

- 移动 (N) 步: 让角色向前移动 N 步
- 右转 (N) 度: 让角色顺时针旋转 N 度
- 左转 (N) 度: 让角色逆时针旋转 N 度
- 移到 x: (X) y: (Y): 瞬间移动角色到指定坐标
- 在 (N) 秒内滑行到 x: (X) y: (Y): 平滑移动角色

## 外观类

- 说 (文本) (N) 秒: 角色显示对话气泡
- 切换造型为 (造型名): 切换角色造型
- 将大小增加 (N): 改变角色大小

## 声音类

- 播放声音 (声音名): 播放声音
- 停止所有声音: 停止所有正在播放的声音
- 将音量设为 (N)%: 设置音量

## 事件类

- 当绿旗被点击: 项目启动时触发
- 当接收到 (消息): 收到广播时触发
- 广播 (消息): 发送广播消息

## 控制类

- 等待 (N) 秒: 暂停执行 N 秒
- 重复 (N) 次: 循环执行内部积木 N 次
- 如果 (条件) 那么: 条件判断
- 克隆 (角色): 创建角色副本

## 侦测类

- 碰到 (目标)?: 检测是否碰到指定目标
- 鼠标的 x 坐标: 获取鼠标 X 坐标
- 回答: 获取询问的回答

## 运算类

- (A) + (B): 加法
- (A) - (B): 减法
- (A) * (B): 乘法
- (A) / (B): 除法
- 随机数 (min) 到 (max): 生成随机数

## 变量类

- 设置 (变量) 为 (值): 变量赋值
- 将 (变量) 增加 (N): 变量增量
- 显示变量 (变量): 在舞台上显示变量监视器
