# 04 Conflict Resolution

04 - 冲突解决算法

1. 概述

多人同时编辑时，冲突解决算法确保数据一致性。Sailfish Studio 针对不同数据类型采用不同的解决策略。

2. 积木树: OT 算法

积木树的操作 (插入、删除、移动、修改参数) 通过 OT 变换函数保证并发操作可交换。

2.1 变换规则

· 两个 block_insert 在不同位置 → 都生效
· 两个 block_insert 在相同位置 → 后到达的偏移 +1
· block_insert + block_delete (不同积木) → 都生效
· block_delete + block_update_field (同一积木) → block_update_field 被丢弃 (积木已删除)
· 两个 block_move (同一积木) → 最后到达的生效

3. 变量: LWW + 操作变换

· 变量修改采用 Last-Writer-Wins (LWW)，以服务器时间戳为准
· 如果两个用户在离线期间修改了同一变量，恢复连接后以最后修改为准
· 增量修改 (change variable by N) 转换为绝对值后应用 LWW

4. 造型编辑: 锁定机制

· 同一时间只能有一个用户编辑造型，进入造型编辑器时锁定
· 锁定期间其他用户看到只读视图和锁定提示
· 用户离开造型编辑器时自动解锁
· 锁定超时: 5 分钟无操作自动解锁（防止用户忘记关闭而长期锁定）

5. 角色属性: LWW

· 角色位置、大小、方向等属性使用 LWW
· 两个用户同时移动同一角色，最后一次操作生效
