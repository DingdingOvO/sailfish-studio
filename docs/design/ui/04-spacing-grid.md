# 04 - 间距与网格

[返回 README](../README.md)

## 1. 基准网格

采用 8px 基准网格，所有间距、内边距、外边距、组件尺寸均为 8 的倍数。这种设计确保任何屏幕上的像素对齐，避免亚像素模糊。

## 2. 间距令牌

| Token | 值 | 用途 |
|-------|----|------|
| `--space-0` | 0px | 无间距 |
| `--space-1` | 4px | 微小间距：图标与文字间距 |
| `--space-2` | 8px | 小间距：组件内元素间距 |
| `--space-3` | 12px | 中间距：相关元素组间距 |
| `--space-4` | 16px | 标准间距：面板内边距 |
| `--space-6` | 24px | 大间距：模块间间距 |
| `--space-8` | 32px | 超大间距：页面级间距 |
| `--space-12` | 48px | 区块级间距 |

## 3. 布局网格

- 工具箱宽度: 240px (30 × 8)
- 右侧面板宽度: 272px (34 × 8)
- 舞台最小尺寸: 480 × 360px
- 工具栏高度: 40px
- 状态栏高度: 28px
- 标题栏高度: 36px (macOS) / 32px (Windows/Linux)

## 4. 对齐规则

- 所有容器内边距使用 `--space-4` (16px)。
- 相邻组件间距使用 `--space-2` (8px) 或 `--space-3` (12px)。
- 标签与对应控件间距使用 `--space-1` (4px)。
- 分组标题与组内第一条内容间距为 `--space-3` (12px)，组内最后一条内容与下一组标题间距为 `--space-6` (24px)。
