# 05 - 性能调优

## Wasm 内存优化

- 使用 `wasm-opt -Os` 压缩
- 启用 wee_alloc 轻量分配器
- 资源懒加载，避免全量加载到 Wasm 内存

## 渲染性能

- 使用 WebGL 批量绘制 (按纹理排序)
- 脏矩形检测避免全画布重绘
- 克隆体使用对象池

## CDN 缓存策略

- 静态资源: max-age=31536000 (一年)
- HTML 文件: max-age=0 (每次验证)
- API 响应: max-age=60 (1 分钟)

## 数据库查询优化

- 积木树查询使用预编译语句
- 资源 BLOB 仅在需要时读取
- 定期 VACUUM 清理碎片
