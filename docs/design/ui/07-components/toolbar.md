# Toolbar

工具栏组件规范

1. 用途

编辑器主工具栏，提供常用操作的快捷入口。

2. 尺寸

· 高度: 40px
· 按钮尺寸: 32px × 32px
· 图标尺寸: 20px
· 分隔线: 1px --border-color，垂直，上下内边距 8px
· 分组间距: --space-3

3. 按钮布局（从左到右）

· 文件操作组: 新建、打开、保存
· 撤销/重做组: 撤销、重做
· 运行控制组: 绿旗（运行）、停止
· 视图控制组: 全屏、舞台尺寸切换（小/大/全屏）
· 模式切换组: 加速模式开关
· 协作组（右对齐）: 分享按钮、当前协作用户头像

4. 溢出菜单

· 当工具栏宽度不足以显示所有按钮时，超出的按钮收起到右侧的 "…" 溢出菜单
· 溢出菜单内容为下拉菜单样式，包含被折叠的按钮
· 用户可通过拖拽按钮重新排序工具栏
