# 06 - UI 与设计语言

[上一章](./05-collaboration.md) | [下一章：扩展与插件](./07-extensions.md)

## 6.1 设计风格
参考 Figma 简洁现代风格。默认蓝色（#2563EB）唯一强调色。深色模式背景 #121212。插件可扩展主题。

## 6.2 编辑器布局
- 标题栏（macOS 保留红绿灯）
- 菜单栏：文件/编辑/查看/项目/工具/扩展/帮助
- 工具栏：绿旗、停止、全屏、加速模式、撤销/重做、分享按钮
- 左侧工具箱 + 中间编辑区 + 右侧舞台和面板
- 协作参与者列表（工具栏右侧）
- 评论面板（可折叠侧边栏）
- 文件暂存区面板
- 状态栏：性能仪表盘、同步状态指示器

## 6.3 用户存在感 UI
协作用户光标彩色标记 + 名称。编辑中的积木显示用户颜色边框。加入/离开 Toast 通知。

## 6.4 多语言
50 种语言，AI 辅助翻译。RTL 布局支持。

## 6.5 可访问性
全键盘操作，WCAG 2.1 AA 标准。
