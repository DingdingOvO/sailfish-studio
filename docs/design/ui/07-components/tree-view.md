# 树形视图组件规范

[上一节：弹窗](./dialog.md) | [下一节：积木画布](./block-canvas.md)

## 1. 用途

- 角色列表 (树形: 角色 → 造型/声音)
- 设置中心导航
- 项目文件浏览器

## 2. 节点样式

- 高度: 28px
- 缩进: 每级 `--space-6` (24px)
- 展开/折叠箭头: 16px 图标, 位于节点左侧
- 节点文本: `--text-sm`, `--text-primary`
- 选中节点: 背景 `--color-primary-light`, 文本 `--color-primary`
- 悬停节点: 背景 `--bg-surface` + 不透明叠加

## 3. 交互

- 单击: 选中节点。
- 双击: 展开/折叠 (若为父节点) 或打开/重命名 (若为叶节点)。
- 支持拖拽排序 (角色列表) 和跨树拖拽 (素材暂存区 → 角色列表)。
- 键盘导航: ↑↓ 移动焦点, ←→ 折叠/展开, Enter 选中, F2 重命名。
