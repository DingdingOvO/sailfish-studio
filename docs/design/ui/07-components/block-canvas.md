# 积木画布组件规范

[上一节：树形视图](./tree-view.md) | [下一节：状态栏](./status-bar.md)

## 1. 概述

积木编辑器核心区域，基于 Canvas 2D 渲染，由 sf-blocks 提供。所有积木的布局、渲染、交互都在此画布上完成。

## 2. 积木渲染

- 背景色按类别 (见 [色彩体系](../02-color-system.md))。
- 圆角: 6px。
- 凹槽 (Notch)/凸起 (Bump): 用于表示连接点，尺寸 8px × 4px。
- 文本: 等宽字体, 13px, 居中。
- 高亮状态:
  - 选中: 2px 蓝色边框 (`--color-primary`)。
  - 连接候选: 2px 绿色边框 (`--color-success`)。
  - 非法连接: 2px 红色边框 (`--color-error`)。
  - 协作中其他用户编辑: 2px 用户颜色边框。

## 3. 交互

- 拖拽移动: 实时跟随鼠标，吸附距离 8px (`MAGNETIC_SNAP_DISTANCE_PX`)。
- 连接/断开: 释放时自动连接或断开。
- 动态模糊拖尾: 见 [动画规范](../06-motion.md) 3.4 节。
- 右键菜单: 复制、粘贴、删除、注释、折叠、添加评论。
