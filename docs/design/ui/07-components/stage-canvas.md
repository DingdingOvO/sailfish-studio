# Stage Canvas

舞台画布组件规范

1. 概述

项目运行时的显示区域，由 sf-renderer 提供 WebGL/WebGL2 渲染。所有角色、背景、画笔效果都在此画布上绘制。

2. 尺寸

· 默认舞台尺寸: 480 × 360px（STAGE_DEFAULT_WIDTH × STAGE_DEFAULT_HEIGHT）
· 最小: 240 × 180px，最大: 3840 × 2160px (4K)
· 宽高比: 始终 4:3，超出区域用黑色填充（letterbox）
· 编辑器中舞台默认缩放以适配面板，用户可手动缩放（25%～400%）

3. 渲染层叠顺序（从下到上）

· 背景层（舞台背景图片/颜色填充）
· 角色层（所有可见角色，按层级排序）
· 画笔层（所有画笔绘制内容）
· UI 覆盖层（绿旗按钮、停止按钮，仅在编辑器中显示）

4. 交互（编辑器中）

· 点击角色选中，拖拽移动
· 右键角色弹出上下文菜单（复制、删除、导出为 .sprite）
· 双击舞台区域切换全屏
· 缩放: Ctrl+滚轮 或 双指捏合

5. 运行模式

· 点击绿旗：项目开始执行，角色响应积木逻辑
· 点击停止：终止所有脚本，重置角色状态
· 运行中舞台边框显示绿色呼吸灯（--color-success，2px，透明度在 0.3～0.8 间循环，周期 2 秒）
