# 06 - 动画规范

[返回 README](../README.md)

## 1. 动画原则

- **功能性优先**: 动画用于提供反馈、引导注意力、平滑过渡，不做纯装饰性动画。
- **持续时间**: 所有动画持续时间 ≤ 300ms，常用 150ms，瞬间反馈用 100ms。
- **缓动函数**: 默认 `ease-out` (cubic-bezier(0, 0, 0.2, 1))，弹跳效果用 `cubic-bezier(0.68, -0.55, 0.265, 1.55)`。

## 2. 动画令牌

| Token | 值 | 用途 |
|-------|----|------|
| `--duration-instant` | 100ms | 瞬间反馈：悬停态变化、按钮按下 |
| `--duration-fast` | 150ms | 快速过渡：面板折叠/展开、tooltip 显示/隐藏 |
| `--duration-normal` | 200ms | 标准过渡：弹窗打开/关闭、下拉菜单 |
| `--duration-slow` | 300ms | 慢速过渡：欢迎页动画、页面切换 |

## 3. 动画场景规范

### 3.1 按钮交互

- 悬停: 背景色 150ms ease-out 过渡。
- 按下: 缩放至 95%，100ms ease-out。
- 释放: 弹回 100%，150ms ease-out。

### 3.2 弹窗

- 打开: 从透明度 0、缩放 0.95 过渡到透明度 1、缩放 1，200ms ease-out。同时背景遮罩从透明度 0 过渡到 0.5。
- 关闭: 反向过渡，150ms ease-in。

### 3.3 面板折叠

- 内容区使用 `max-height` 过渡，从当前高度到 0 (或反向)，150ms ease-out。不使用 `height: auto` 过渡以避免计算性能问题，而是用 JavaScript 在过渡前测量实际高度。

### 3.4 动态模糊拖尾 (积木拖拽)

- 由 sf-blocks-trail 模块实现，在独立 Canvas 层绘制。
- 拖尾帧数: 6 帧。
- 透明度: 0.8 递减至 0.1，步长均分。
- 帧位置采集间隔: 与渲染帧率同步 (60fps)，不额外采样子帧。
