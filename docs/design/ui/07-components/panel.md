# Panel

面板组件规范

1. 用途

右侧面板区域，包含角色列表、属性面板、造型编辑器、声音编辑器。

2. 尺寸

· 默认宽度: 272px
· 最小宽度: 160px，最大宽度: 400px
· 通过拖拽左侧边框调整宽度
· 面板内容滚动：使用 overflow-y: auto，隐藏滚动条但保留滚动能力（hover 时显示 6px 滚动条）

3. 面板切换

· 顶部选项卡切换不同面板（角色、造型、声音）
· 选项卡高度: 32px
· 当前面板类型以 --color-primary 底部指示条标识

4. 面板折叠

· 面板可完全折叠（收起时宽度为 0），通过工具栏按钮或快捷键 Ctrl+Shift+P 切换
· 折叠/展开过渡: 150ms ease-out，宽度从 0 到实际宽度
