# 05 Marketplace

05 - 扩展与插件市场设计

1. 概述

扩展市场和插件市场是同一个平台的两个视图，用户可以在编辑器中或通过网站访问。

2. 市场功能

2.1 搜索与浏览

· 关键词搜索（名称、描述、标签）
· 按分类浏览（工具、3D、数据、系统、社区精选等）
· 按筛选条件排序（下载量、评分、更新时间、名称）

2.2 扩展/插件详情页

· 图标、名称、作者、版本、下载量、评分
· 描述、截图/演示视频
· 提供的积木列表（扩展）或功能介绍（插件）
· 权限声明
· 更新日志

2.3 安装

· 一键安装到编辑器（通过 sailfish://install 协议或直接调用 API）
· 安装后无需重启编辑器即可使用

3. 审核流程

· 提交: 开发者在市场网站提交扩展/插件，填写描述、上传代码
· 自动检查: 静态扫描（XSS、权限声明一致性、代码签名完整性）
· 人工审核: 功能测试、安全检查、UI 一致性检查
· 审核结果: 通过（汇入官方市场）、修改后重审（附具体修改建议）、拒绝（附明确理由）
· 更新时间: 审核周期目标 < 3 个工作日
