# 01 - 快速入门

## 欢迎来到 Sailfish Studio！

Sailfish Studio 是一个高性能的图形化编程平台。您可以在这里创作游戏、动画、应用，甚至开发服务器后端。

## 访问 Sailfish Studio

- Web 版: 打开浏览器，访问 https://editor.sailfish.studio
- 桌面版: 从 GitHub Releases 下载安装包

## 认识界面

1. 工具栏: 绿旗(运行)、停止、保存、撤销/重做
2. 工具箱: 左侧，包含所有可用积木
3. 积木编辑区: 中间，拖拽积木的地方
4. 舞台: 右上角，项目运行显示区域
5. 角色列表: 右下角，管理所有角色

## 创建第一个项目

1. 点击工具栏的"新建"按钮
2. 从工具箱拖一个"说 (你好!)"积木到编辑区
3. 从工具箱拖一个"当绿旗被点击"积木，连接到上方
4. 点击绿旗按钮
5. 舞台上角色说出"你好!"

## 保存项目

- 按 Ctrl+S 或点击工具栏"保存"
- 项目保存为 .sf 文件
