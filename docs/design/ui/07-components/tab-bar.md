# Tab Bar

选项卡组件规范

1. 用途

编辑器顶部的项目选项卡切换。

2. 尺寸

· 选项卡高度: 36px
· 最小宽度: 100px，最大宽度: 200px
· 选项卡间距: 0（相邻贴合）
· 图标: 16px，文件类型色

3. 状态

· 选中: 背景色 --bg-surface，底部 2px --color-primary 指示条
· 未选中: 背景色 --bg-primary，底部无指示条
· 悬停: 背景色 --bg-surface + 不透明叠加
· 未保存: 选项卡标签右侧显示圆点（--color-warning，直径 6px）

4. 交互

· 点击选中，双击重命名（进入内联编辑模式）
· 拖拽排序，拖出选项卡栏可在新窗口打开
· 关闭按钮：悬停时出现在选项卡右侧，图标 16px
· 右键菜单：关闭、关闭其他、关闭右侧、关闭所有
· Ctrl+Tab 切换到下一个选项卡，Ctrl+Shift+Tab 切换到上一个
