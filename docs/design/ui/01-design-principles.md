# 01 - UI 设计原则

[返回 README](../README.md)

## 1. 概述

Sailfish Studio 的界面设计遵循以下核心原则，确保界面不仅美观，且高效、可预测、无障碍。所有组件和布局设计必须符合这些原则。

## 2. 核心原则

### 2.1 清晰性 (Clarity)

- **信息层级**: 每个界面元素应有明确的视觉层级。标题、正文、辅助文本通过字号、字重、颜色区分。
- **状态明确**: 控件的状态 (默认、悬停、按下、禁用、聚焦、选中) 必须有清晰的视觉差异。聚焦态始终显示键盘焦点环 (2px 蓝色外框)。
- **语义明确**: 图标必须配文本标签 (除非是极端通用图标，如"播放"、"停止")。错误提示必须说明原因和建议操作。

### 2.2 一致性 (Consistency)

- **统一设计语言**: 所有组件共享相同的设计令牌 (颜色、间距、圆角、阴影)。按钮圆角统一为 6px，输入框圆角为 6px，弹窗圆角为 12px。
- **行为一致**: 相同的交互在不同位置产生相同结果。任何可拖拽元素都使用相同的拖拽反馈 (半透明跟随、吸附高亮)。
- **响应式一致**: 编辑器的核心功能在桌面、Web、平板上保持一致体验，仅布局适配，功能不减。

### 2.3 效率 (Efficiency)

- **操作可达**: 常用操作 (运行、停止、保存、撤销) 可通过工具栏、键盘快捷键、右键菜单三种方式触发，互不依赖。
- **减少摩擦**: 拖入素材自动识别类型并放置到正确位置。扩展安装后无需重启编辑器即可使用。
- **智能记忆**: 编辑器记住用户上次使用的工具箱分类、面板宽度、窗口大小，跨会话保留。

### 2.4 专业感 (Professional)

- **克制设计**: 不使用过多颜色。蓝色为唯一强调色，状态色仅用于错误 (红)、成功 (绿)、警告 (橙)。
- **高密度但有序**: 面板可折叠，工具栏可定制，信息密度由用户控制。默认布局提供合理的信息密度，既不空旷也不拥挤。
- **深色模式原生体验**: 深色模式背景为纯黑调 (#121212)，面板稍浅 (#1E1E1E)，文字对比度满足 WCAG AA 标准。

### 2.5 包容性 (Inclusivity)

- **无障碍优先**: 所有交互可通过键盘完成，满足 WCAG 2.1 AA 标准。屏幕阅读器可正确朗读界面元素。
- **国际化**: 支持 50 种语言，包括 RTL 布局 (阿拉伯语、希伯来语)。文本预留 30% 扩展空间以应对翻译后文本增长。
- **性能公平**: 在低端设备上 (如 4GB 内存)，界面不降级但资源消耗设上限 (256MB Wasm 堆)。

## 3. 适用范围

此原则适用于所有 UI 组件、布局、动画和交互设计。
