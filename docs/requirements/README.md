## 关于 Sailfish Studio

Sailfish Studio 是一个面向专业创作者的高性能图形化编程与全栈开发平台。它源于 Scratch 的积木编程理念，通过 Rust 重写核心引擎、自研 UI 框架和纯文本语言，将创作能力从游戏、动画扩展到服务器后端、桌面应用和移动端。
