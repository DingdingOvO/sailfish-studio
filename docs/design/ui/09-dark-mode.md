# 深色模式规范

[返回 README](../README.md)

## 1. 切换方式

- 用户通过设置面板切换: "外观" → "浅色 / 深色 / 跟随系统"。
- 默认跟随系统 (通过 `prefers-color-scheme` 媒体查询)。
- 插件可扩展更多主题，但深色模式的基础规则由系统保证。

## 2. 色彩映射

见 [色彩体系](./02-color-system.md) 深色模式令牌。所有颜色通过 CSS 变量切换，组件不硬编码颜色。

## 3. 过渡

- 切换主题时，背景和文字颜色通过 200ms ease-out 过渡，避免闪烁。使用 `transition: background-color 200ms, color 200ms` 在 `:root` 级别应用。

## 4. 图像与资源

- 矢量图标自动适配文字颜色，无需特别处理。
- 位图资源 (如角色缩略图) 在深色模式下保持原样，但在外围添加 1px 浅色边框以提高边界可见性。
