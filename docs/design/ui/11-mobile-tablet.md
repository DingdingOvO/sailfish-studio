# 11 Mobile Tablet

平板/触控适配规范

1. 概述

针对 Android 平板 (最小 1024×768 逻辑像素) 的触控优化设计。

2. 布局变化

· 竖屏: 积木画布占据上半部分 (60%)，工具箱折叠为底部横条，舞台缩小到右上角悬浮窗
· 横屏: 与桌面布局相同，但面板宽度缩减为 200px
· 所有面板可通过边缘滑动手势唤出/隐藏

3. 触控优化

· 积木块最小触控区域: 44×44px (符合 iOS/Android 无障碍触控标准)
· 吸附距离在触控模式下扩大到 12px（手指精度低于鼠标）
· 双指捏合缩放积木画布，双指旋转切换角色方向
· 长按积木 500ms 触发右键菜单（等同于桌面端右键）
· 双手同时拖拽不同积木：支持独立的多点触控跟踪

4. 暂存区

· 屏幕底部面板，从底部上滑唤出
· 拖出窗口改为拖到屏幕边缘触发分享菜单或保存菜单
· 拖入通过系统文件选择器或分屏拖拽实现
